# 継承した[!DNL Marketo Engage] インスタンスを監査するためのヒントとテクニック

*Source: Adobe Marketo Champion*

複数のユーザーによって管理されているライブ [!DNL Marketo Engage] インスタンスを継承する場合は、不適切と思われるすべてのメモを作成する可能性があります。 タスクを分類し、長い道のりを行くタスクに優先順位を付けることで、クリーンアップと最適化の作業を整理することが重要です。

この「継承されたインスタンス監査のヒントとテクニック」チュートリアルは、[!DNL Adobe]人のMarketo Championから入手したもので、新規管理者に対するステップバイステップのガイダンスを提供します。 このチュートリアルには、ダウンロード可能な[監査チェックリスト ](https://experienceleague.adobe.com/docs/marketo/using/getting-started-with-marketo/inheriting-a-marketo-engage-instance/where-to-start.html)とテンプレートが含まれており、継承したインスタンスをすぐに開始するのに役立ちます。 チュートリアルに従って、仲間から学ぶことからインスピレーションを得ましょう！

## トピックと学習内容

* **[継承されたインスタンスの監査](/help/marketo-tutorial-inherited-instance/audit-an-inherted-instance.md)**
  *自分にとって新しい既存のインスタンスを監査する方法について説明します。 [!DNL Campaign]のインスペクターなどの、すぐに使えるツールを使用して、継承されたセットアップをテストし、インスタンスに関するインサイトを取得します*

* 簡単なトラブルシューティングのために&#x200B;**[CRM同期エラーを記録します](/help/marketo-tutorial-inherited-instance/log-crm-sync-errors-for-easy-troubleshooting.md)**
  *通知、CRM同期、Launchpoint、およびweb サービスをレビューし、エラーをタイムリーにトラブルシューティングするための管理ルーチンの設定方法を説明します。*

* **[インスタンスガバナンスガイドの作成](/help/marketo-tutorial-inherited-instance/develop-an-instance-governance-guide.md)**
  *プログラムの構築、ガバナンス、全体的なマーケティング業務を最適化するために、迅速な効率性をどのように実現するかを学ぶ*

* **[マーケティングテクノロジースタックを視覚的にマッピングする](/help/marketo-tutorial-inherited-instance/create-a-visual-data-flow-diagram.md)**
  *視覚的なアーキテクチャ図を使用してデータソースをマッピングし、テクノロジースタックを把握する方法を説明します*

* **[プログラムの起動前の品質保証（QA）プロセス](/help/marketo-tutorial-inherited-instance/essential-program-pre-launch-qa.md)**
  *失敗を避けるために、効果的なプログラムの起動前QA プロセスを確立する方法を説明します。*
